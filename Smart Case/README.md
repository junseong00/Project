## 도마뱀 스마트 케이스

- SodaIDE를 기반으로한 기존 스마트팜 모델을 변형한 도마뱀 스마트 케이스
### with
- ESP32
- SMART FARM
- Blynk
- WIFI


# 🦎 스마트 도마뱀 서식지 관리 시스템

## 📌 작품 개요

1. **스마트팜 기술을 활용한 도마뱀 서식지 자동 제어**  
   - 도마뱀 서식지의 온도 및 습도를 스마트하게 조절
2. **DHT22 센서를 이용한 실시간 온습도 모니터링**  
   - 환경 변화를 즉각 감지하고 데이터 시각화
3. **건강한 성장 환경 조성을 위한 효율적 관리 시스템 구축**  
   - 최적의 환경을 유지하여 도마뱀의 건강을 보호

## 🎯 최종 목표

1. **자동화된 환경 관리로 도마뱀의 스트레스 감소**
2. **사용자 편의를 고려한 원격 제어 기능 구현**
3. **지속 가능한 도마뱀 사육 환경 제공**

## 🛠 작품 구성

- **과정 사진 및 디자인** (추가 예정)
- **센서 및 모듈 구성**
  - DHT22 온습도 센서
  - IoT 기반 스마트 컨트롤러
  - 원격 제어 및 실시간 모니터링 대시보드

## 🚀 기대 효과 및 활용 방안

1. **자동화된 서식지 관리로 시간 및 비용 절감**
2. **다양한 환경 조건을 조정하여 특정 생물 연구에 활용 가능**
3. **스마트팜 기술을 확장하여 다양한 애완동물 환경 관리 모델 개발**
4. **교육 목적으로 IoT 및 스마트 기술 학습에 활용 가능**

## ✨ 작품의 특징

- **IoT 기반 실시간 온습도 제어**
- **사용자가 설정한 최적 환경 자동 유지 시스템**
